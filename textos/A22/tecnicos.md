Formato escolhido: mito versus realidade
Ganchos descartados:
- "Testar prompt no ChatGPT não é engenharia." — direto, mas soa acusação.
- "Copiar a interface do Higgsfield é resolver o problema errado." — bom, guardado como variante.
- "A rota do modelo importa mais que o prompt em si." — verdadeiro, mas técnico demais pra gancho.
- "Ninguém fala do que acontece depois que você aperta gerar." — intrigante, mas menos direto.

### FALA

O mito é que dominar IA é saber escrever um bom prompt. A realidade é outra.

O trabalho de verdade começa depois: escolher o modelo e o provedor certos pra cada tarefa, adaptar o prompt às características de cada um, usar referência real e memória de marca, avaliar o resultado automaticamente, e corrigir ou trocar a rota quando falha.

Isso é orquestração. Não é brincar de chatbot — é construir o sistema que decide, controla custo, controla tentativa, e registra tudo pra melhorar a próxima geração.

Mesmos modelos, mais controle. É isso que separa quem testa ferramenta de quem constrói sistema.

## ESTRUTURA
Tese central: o problema nunca foi o modelo de IA — é usar o mesmo modelo sem ninguém escolher a rota certa, corrigir o erro e conferir o resultado por você.
Elemento demonstrável: o contraste entre o chat único parado (prompt manual) e o pipeline de orquestração rodando sozinho (escolhe, adapta, avalia, corrige, registra).
Posição cravada: para o técnico, a competência que vale não é escrever prompt, é construir o sistema de decisão em torno do modelo — e isso é o que separa "usuário de IA" de "engenheiro de IA".
